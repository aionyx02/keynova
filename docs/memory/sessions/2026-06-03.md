# Session 2026-06-03

## Highlights

- Opened `feature/personal-memory` from `main` for a developer-directed AI-workflow
  optimization: a locally-stored, AI-organized personal memory (ADR-0043 proposed).

## COMPLETED: MEM.1.A - personal memory capture + recall MVP

Scope and decisions live in `docs/tasks/personal-memory.md` and ADR-0043.
Settled with the developer: local-model-only personalization (privacy boundary),
surfaces = `remember` / `recall` prefixes + memories-in-search (Phase 3), reuse
`agent_memories` with `scope=personal` (no migration).

Backend:

- `core/ai_capability/parse.rs` (new): `extract_first_json_object` promoted out
  of `gen_command` so `remember` reuses it; `gen_command` now imports it.
- `registry.rs`: added `Remember` (audit) and `Recall` (no audit) ids + parse /
  as_str / META + test coverage.
- `capabilities/remember.rs` (new): LLM organizes a note into `{title, content}`
  (robust parse with original-note fallback), persists via
  `try_store_agent_memory(scope="personal", visibility="private")`.
- `capabilities/recall.rs` (new): no LLM — `agent_memories_blocking(scope=personal)`
  + term ranking (title weight 2, content 1), empty query → recent.
- `mod.rs` match arms; `handlers/ai_capability.rs` list test 5 → 7.

Frontend:

- `parseCapabilityPrefix.ts`: `remember` / `recall` text prefixes (search
  suppression via `useQueryChange` is automatic).
- `types.ts`: `CapabilityId` + `Remember`/`Recall` payload/output types +
  `parseRememberOutput` / `parseRecallOutput`.
- Hooks `useRemember` / `useRecall`; cards `CapabilityMemoryCard` (saved badge)
  / `CapabilityRecallCard` (click row → paste content); `CapabilityResultArea`
  + `CommandPalette` surface wiring (mode derivation, run-state, submit routing,
  card props); `CapabilityHintLine` updated.

Checks: `cargo test` 465 passed / 2 ignored; `cargo clippy --lib -D warnings`
clean; `npm run lint` clean; `npx vitest run` 169 passed / 1 skipped.

Note: `cargo clippy --all-targets` surfaces pre-existing test-module lints in
files not touched here (`config_manager`, `dispatch`, `knowledge_store` test,
`preview`, `unified_result`); the project gate (`cargo clippy -- -D warnings`,
no `--all-targets`) is clean.
