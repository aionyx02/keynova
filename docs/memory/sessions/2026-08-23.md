## COMPLETED: CI.TRUST - close the frontend coverage gap, land the audit gate

PR #35 (`feature/ci-trust-gate` → `dev`). Prompted by an audit of what CI
actually verifies before a merge.

### The real gap: the frontend suite never ran

36 test files / 218 cases, plus eslint at `--max-warnings 0`, live only inside
`npm run verify` — which is wired to `release.yml` and fires on version tags.
Every PR and every push to `main`/`dev` merged without either executing.

Corrected an earlier miscount made during the same audit: Rust coverage is
**not** thin. `cargo test` runs **463 tests** (472 `#[test]` across 72 files,
2 ignored). An earlier "only 5 `#[test]`" figure came from a grep proxy that
caps results; the three `rust (...)` legs have been meaningful all along.

### Stranded work recovered

`hardening/security-perf` had carried `audit.yml`, ADR-0057,
`src-tauri/.cargo/audit.toml`, a preview.rs clippy fix and ~246 lines of
`security.md` verification playbook since 2026-08-13, unmerged. Because
`audit.yml` only triggers on `main`/`dev` and PRs into them, it had never run
once. First execution was on this PR: both `npm audit` and `cargo audit` pass.

### Two places where local and CI measured different things

Both produce the same failure mode — a check that is green in one place and red
in the other — and both are now fixed:

1. **CRLF vs LF.** `docs-guard-size` measured the checked-out file. With
   `core.autocrlf=true`, `current.md`/`active.md` measure 5127B/5165B on Windows
   against 5068B/5071B in git, so the same commit failed the local hook and
   passed the CI job. Now normalizes to LF before measuring.
2. **Toolchain drift.** CI resolves `dtolnay/rust-toolchain@stable` (now 1.98.0)
   while this machine sat on 1.95.0. Rust 1.98 added
   `clippy::chunks_exact_to_as_chunks`, which fired on five `cfg(windows)` call
   sites — so `npm run rust:clippy` said "No issues found" locally against a red
   windows-latest leg. Fixed the five sites (`as_chunks::<N>()`); local
   toolchain updated to 1.98.0 to match.

**Open decision:** nothing pins the Rust toolchain — no `rust-toolchain.toml`,
no `rust-version` in Cargo.toml. A new stable release can turn CI red with zero
code change (this is the second such event; `06691ce` was the first). Pin for
determinism vs float to catch new lints early — developer's call.

### Also changed
