## COMPLETED: STAB.1 - backend crash-log panic hook

Branch `hardening/stabilize-features` (from `main`). New `core/crash_log.rs`:
a process-wide `std::panic::set_hook` installed at the top of `bootstrap::run`
(so even setup-time and async-task panics are caught) that appends one redacted,
single line per panic to `%LOCALAPPDATA%\Keynova\crash.log`, then chains to the
previous hook. Redaction replaces *all* home-path occurrences (not just prefix),
caps a message at 500 chars and the file at 64 KB (oldest lines rotate out), and
the writer is best-effort (never panics/blocks). `/diag` now shows the last
crash (new `last_crash` field through `DiagnosticsInputs`/`Report`/`render_text`,
read via `crash_log::read_last_crash`). ADR-0051 (proposed); `security.md` §12 +
§3.2 path row added. Pure helpers (`format_entry`, `append_bounded`,
`read_last_crash`) unit-tested (5 tests).

## COMPLETED: STAB.2 - /diag edge-case correctness

- `diagnostics::collapse_home` now collapses only on a real path-component
  boundary, so a home like `/home/al` no longer mangles `/home/alice/...`.

  `path_size_bounded`, so `/diag` can't stall on a huge or symlink-cyclic tree;
