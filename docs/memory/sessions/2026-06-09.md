### Branch-protection runbook (run with an admin-scoped `gh` auth)

Enforces the existing "never merge without review" policy on `main` (repeat with
`dev`). Requires the CodeQL + docs-guard checks to pass and a PR review:

```bash
gh api -X PUT repos/aionyx/keynova/branches/main/protection \
  -H "Accept: application/vnd.github+json" \
  -f "required_status_checks[strict]=true" \
  -f "required_status_checks[contexts][]=Analyze (javascript-typescript)" \
  -f "required_status_checks[contexts][]=Analyze (rust)" \
  -f "required_status_checks[contexts][]=docs" \
  -F "enforce_admins=false" \
  -F "required_pull_request_reviews[required_approving_review_count]=1" \
  -F "restrictions=null"
```

Notes: status-check context names must match the job names once a run has reported
them (the CodeQL job renders as `Analyze (<language>)`, docs-guard as `docs`).
`enforce_admins=false` keeps the solo-maintainer unblocked; flip to `true` later
if a second contributor joins.
