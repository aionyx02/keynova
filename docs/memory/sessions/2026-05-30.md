## Measurement Notes

- Production build after the follow-up emitted `assets/index-*.js` at `104.28 kB` gzip `30.00 kB`.

- `react-vendor` (`192.50 kB`), `terminal-vendor` (`330.51 kB`), and `markdown-vendor` (`334.65 kB`) remain intentionally split from the hot path and only load on demand.
- Before the native WebView2 pass, the isolated Keynova app tree measured about `464.4 MB WS / 276.7 MB PM`.
- After `additionalBrowserArgs` GPU disable, the same app tree dropped to about `343.8 MB WS / 125.9 MB PM`.
- After the WebView2 memory target level hook:
  - hidden steady state (30s after cold hidden launch): `77.7 MB WS / 126.7 MB PM`

- The user’s `200 MB` target is therefore met on the measured debug app-only tree for both hidden steady state and re-activated launcher state. Remaining work is mostly validation and deciding whether release-build measurement should become the new documented baseline.
