# Session 2026-07-19

## COMPLETED: SEC.ADV1 - adversarial-validation bug sweep + first remediation batch

### Scope

Ran an adversarial ("對抗式驗證") review of the whole project (3 parallel
exploration passes: Rust panic/exec surface, React parsing/dispatch/race
surface, AI-capability/workflow/ranking surface) + source cross-verification.
18 findings graded HIGH/MED/LOW. Full catalog + repro steps in the plan file
`compiled-stargazing-flame.md`. This session fixed the crash/robustness tier and
two contract-hardening items; the approval-gate architecture items are deferred
to a decision.

### Fixed (verified: `cargo test --lib` 469 pass + clippy clean; vitest + eslint + tsc clean)

Backend:
- **H1** `calculator_manager.rs` (`try_base_conversion`/`try_currency_conversion`/
  `try_unit_conversion`): `s.to_lowercase()` → `s.to_ascii_lowercase()` at the
  three sites whose offset slices `s`. Unicode lowercase can change byte length,
  so `s[..idx]` (idx from the lowercased copy) panicked on a non-char-boundary
  (`\u{212A} to dec`), and the panic poisoned the calculator `Mutex` permanently
  (`panic=unwind`). Regression test added.
- **M1** `dev_runner.rs::bound_output_n`: truncate at the largest char boundary
  `<= limit` (`is_char_boundary` retreat, mirroring `unified_result.rs`) instead
  of slicing at a fixed 64 KiB byte offset. Regression test added.
- **M2** `calculator_manager.rs::eval`: 4096-byte input cap before the depthless
  recursive-descent parser, preventing a `"("`-bomb stack-overflow abort.
  Regression test added.
- **L1** `model_manager.rs::parse_library_tag_candidates`: clamp the `+900`
  registry-HTML snippet slice to a char boundary.
- **L11** `knowledge_store/sql.rs`: read `succeeded` as `Option<i64>` then map to
  bool, so a stray value can't fail the whole `suggest_next` query.
- **H2** `fix_error.rs`: reject `Payload::RunCommand` (`UnsupportedAction`),
  restoring the documented explanation-only contract. It had caller-controlled
  `args`+`cwd`, no approval gate, and spawned via `run_bounded_dev_cmd`
  (`cargo check` runs build.rs, `npm run` runs package.json scripts). Frontend
  never sent it (grep: zero usages). ADR-0057 (proposed). Test added.
- **M5** `ai_capability/command.rs::risk_tag_for_command`: shell metachars
  (`& | ; > < \` $ ( )` / newlines) force confirm; safe prefixes match on a word
  boundary so `lsof`/`dir & del`/`git status && …` no longer read as safe.
  ADR-0057 (proposed). Tests added.

Frontend:
- **L7** `useInputMode.ts`: lstrip before testing `>`/`/` sigils (consistent with
  downstream capability parsers). Regression test added.
- **M6** `useCapability.ts`: if a newer `run()` started while awaiting `listen`
  subscription, unlisten the orphaned pair instead of overwriting the ref and
  leaking them until unmount.
- **L8** `useSearchStream.ts`: `Array.isArray(payload.items)` guard on the search
  chunk listener (the one IPC-return path skipping field validation).
- **L10** `CapabilityCommandCard.tsx` / `CapabilityListCard.tsx`: guard non-finite
  `confidence`/`last_executed_at` (NaN no longer renders as "high"/`NaN%`, bad
  epoch no longer "Invalid Date").
