## COMPLETED: MEM.1.B - local-model personalization + prompt budget

Scope and decisions live in `docs/tasks/personal-memory.md` and ADR-0043 (proposed).
Privacy boundary: personal memory is injected into capability prompts only when the
resolved provider is local (ollama); cloud providers inject nothing.

Backend:

- `core/ai_capability/memory.rs` (new): `push_memory_sources(store, query, sources)`
  reads `scope="personal"` rows (`agent_memories_blocking`), term-ranks (title
  weight 2, content 1), and pushes up to 3 as `GroundingSource`s via
  `visibility_filtered_source` (secret-shaped content still redacted as defence in
  depth). Best-effort: store errors are swallowed so grounding never blocks a
  capability. `term_score` promoted here and reused by `recall.rs` (dropped its
  private `score_match` duplicate).
- `contract.rs`: `CapabilityDeps.allow_memory_grounding` flag (privacy gate).
- `handlers/ai_capability.rs`: sets the flag from
  `matches!(runtime.provider, AiProvider::Ollama { .. })`, computed before
  `runtime` is moved into the chat provider.
- `explain.rs` / `fix_error.rs` / `gen_command.rs`: call `push_memory_sources`
  only when `allow_memory_grounding` is set, keyed on the user query / raw error /
  intent respectively.
- `prompt.rs`: over-budget fallback now trims the lowest-priority sources (from the
  tail) one at a time, preserving the highest-priority context, instead of dropping
  the whole context block wholesale; only when system + task alone overrun does it
  truncate at the char boundary. Split out `render()` helper.

Tests:

- `memory.rs`: matching memory pushed as a `memory` source; secret-shaped memory
  redacted (`redacted_reason = "secret"`).
- `explain.rs`: injects personal memory when grounding allowed; omits it for a
  cloud provider (via a `CapturingProvider` that records the prompt).
- `prompt.rs`: incremental trim keeps a partial context block instead of dropping
  all sources.
- `allow_memory_grounding: false` added to every existing capability test's deps
  builder + `live_tests.rs`.

Checks: `cargo test --lib ai_capability` 41 passed; `ai_capability::memory` 2
passed; project gate `cargo clippy -- -D warnings` clean. Fixed one
`Range::contains` clippy lint in the new prompt test (only visible under
`--all-targets`).
