## Detailed Notes

### REF.6.B explain response regression

Root cause:

- `useCapability` listened for dotted Tauri event topics
  (`capability.response`, `capability.stream.chunk`), while the frontend event
  convention receives the bridge alias topics (`capability-response`,
  `capability-stream-chunk`), matching existing search and AI stream hooks.
- `useCapabilityStream` rendered only accumulated chunk text. If the final
  `capability-response` arrived without an incremental chunk, the answer card
  could complete with empty text.
- `CapabilityAnswerCard.tsx` also contained broken UI strings in the current
  worktree; those were normalized to ASCII labels while preserving card
  behavior.

Fix:

- Switched capability listeners to the dashed alias event topics.
- Added final-response text fallback in `useCapabilityStream`.
- Added regression coverage proving the hook listens to `capability-response`
  and `capability-stream-chunk`, and renders final response text even without a
  chunk.
