## Detailed Notes

### Backend module shape

- `core/ai_capability/mod.rs` — single public entry `call_capability(req, deps)`; compile-time `match` on `CapabilityId` (enum-based registry, no `dyn Capability`).
- `core/ai_capability/registry.rs` — `CapabilityId::{Explain,Summarize,FixError}` + static `CapabilityMeta` table; `meta(id).audit` and `accepts_context_hash` are fixed at registration per ADR-0030 §4, never returned per-call.
- `core/ai_capability/contract.rs` — `CapabilityRequest`, `CapabilityResponse`, `CapabilityOutput::{Text,Structured}`, `CapabilityError::{UnknownId,InvalidPayload,ProviderError,Cancelled,UnsupportedAction}`. `ChatProvider` trait abstracts the LLM call so unit tests can stub; production impl is `AiManagerChatProvider` wrapping `AiManager::chat_sync` / `chat_sync_stream`. `StreamChunkFn` alias keeps clippy `type_complexity` happy.
- `core/ai_capability/prompt.rs` — `CAPABILITY_PROMPT_BUDGET_CHARS = 1400`, `CAPABILITY_PROMPT_SOURCE_LIMIT = 6`, `CAPABILITY_SNIPPET_MAX_CHARS = 160`. Budget overrun drops the context block first, then truncates the task body via `core::grounding::truncate` (char-boundary safe). `maybe_audit` writes through `KnowledgeStoreHandle::try_log_agent_audit` only when `audit_required == true`.

### Capabilities

- `explain` — pulls workspace/commands/notes/history sources via `LocalContextSearcher`, best-effort (errors non-fatal). `audit = true`, `risk_tag = none()`.
- `summarize` — pure text transform, no local grounding. `audit = false`, `risk_tag = none()`.
- `fix_error` — accepts either `{raw_output}` (preferred, no exec) or `{program,args,cwd,timeout_secs}` which re-runs via `core::dev_runner::run_bounded_dev_cmd`. Program allowlist: `cargo`, `npm`, `pnpm`, `yarn`, `tsc`. Any `{apply:...}` variant returns `UnsupportedAction` (file-mutating fix path deferred to a future ADR). `audit = true`, `risk_tag = none()`.

### Handler + wiring

- `handlers/ai_capability.rs` — `capability.list` / `capability.call` / `capability.cancel`. Worker is `std::thread::spawn`; per-`request_id` `Arc<AtomicBool>` cancel flag in a `HashMap`. No global single-flight — distinct request ids may run in parallel; per-chip UI disable owns serialization (ADR-0029 §4 state-based). Streaming emits `capability.stream.chunk` events; terminal event is `capability.response`.
- `core/local_context.rs` — added `#[derive(Clone)]` so the handler can clone the searcher into each spawned thread cheaply (all fields are already `Arc`).
- `managers/ai_manager.rs` — added `chat_sync` + `chat_sync_stream` blocking shims (single-user-turn, no history mutation; reuse existing `do_chat` / `do_chat_stream`).
- `app/state.rs` — registered `AiCapabilityHandler` with `LocalContextSearcher` constructed from the same managers the agent handler uses, plus `KnowledgeStoreHandle` and the event bus.
- `core/mod.rs`, `handlers/mod.rs` — exposed the new modules.

### Frontend feature

- `src/features/ai-capability/types.ts` — TS twin (`CapabilityId`, `CapabilityMeta`, `CapabilityOutput`, request/response event payloads, per-capability payload types). Re-uses `RiskTag` and `parseRiskTagFailSafe` from `src/types/unified-result.ts` — no duplication.
- `src/features/ai-capability/hooks/useCapability.ts` — generic single-call hook. State-based `isLoading` for ADR-0029 §4 in-flight disable. Subscribes to `capability.response` (filtered by `request_id`) + optionally `capability.stream.chunk`. Outside Tauri (`window.__TAURI_INTERNALS__` absent) it short-circuits listener setup, matching the jsdom pattern in `useSearchBackend`.
- `src/ipc/routes.ts` — added `CAPABILITY_LIST` / `CAPABILITY_CALL` / `CAPABILITY_CANCEL`.
