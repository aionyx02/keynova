# Keynova v0.7.1

A stability and performance point release. No new features and no breaking
changes — the daily search-first path is the same, just quieter, faster, and now
guarded by per-push cross-platform CI.

## Fixes

- **No more black console flash.** Subprocess spawns on Windows could briefly pop
  a black console window that stole focus from the launcher. Every spawn now goes
  through `CREATE_NO_WINDOW` (`core::SilentCommandExt` / `.no_window()`), so
  nothing flashes.

## Performance

- **Native Windows shell-icon extraction.** App/file icons are now pulled
  directly from the Windows shell instead of one PowerShell process per icon,
  cutting per-result spawn overhead and latency.
- **Memoized hardware probe.** The local-model hardware probe is cached instead of
  re-shelling `wmic` / `nvidia-smi` on every check, removing repeated subprocess
  spawns.

## CI / Stability

- **Per-push cross-platform CI.** A new `ci.yml` matrix runs the frontend build →
  `clippy -D warnings` → `cargo test` on `ubuntu-22.04`, `macos-latest`, and
  `windows-latest` on every push. Previously Linux/macOS were only compiled at
  release-tag time, so platform regressions surfaced late; they are now caught on
  push. All three platforms verified green for this release.
- Static review of every `cfg(not(windows))` / macOS / Linux / unix path confirmed
  they degrade gracefully (Err/None/Unavailable) with no panics.

## Safety Notes

- The app remains **unsigned**; the signing pipeline is scaffolded but certs are
  not yet configured (SmartScreen / Gatekeeper will still warn).
- AI-generated commands stay **copy-only**; there is no generic shell execution.
- At-rest secrets live in the OS keychain; risky file actions keep their
  preview/confirm gates.
