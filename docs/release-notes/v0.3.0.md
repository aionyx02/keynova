# Keynova v0.3.0

## Highlights

- Search-first AI interaction is now fully capability-driven. The palette supports inline `explain`, `summarize`, `fix`, `next`, and AI command generation without bringing the legacy chat-first flow back into the hot path.
- Natural-language routing is lower-friction. Empty palette state can surface suggested next actions, and no-result intent queries can escalate into AI command generation automatically.
- Workflow memory is now strong enough to replay recent command-style actions and rank likely follow-ups.
- Idle-memory work on Windows significantly reduced the launcher's steady-state footprint, especially when the window is hidden or inactive.

## What Changed

- Completed the REF.6 capability rollout:
  - backend `gen_command` and `suggest_next`
  - `fix <error>` capability wiring
  - empty-state `next` suggestions
  - NL fallback routing for `explain` / `summarize` / `fix` / `cmd`
  - feature-first frontend layout and shared component extraction
- Landed REF.7 runtime/perf follow-through:
  - `ai.legacy_agent = false` path and legacy mount gate
  - quantitative guard scripts and bench helpers
  - memory-oriented lazy loading for cold panels and markdown
- Improved development ergonomics:
  - `npm run tauri dev` now reuses an existing Keynova Vite server instead of failing on port `1420`
  - stale debug `tauri-app.exe` instances are shut down before a new native dev launch to avoid Windows file-lock failures

## Performance and Stability

- Main eager frontend chunk is down to roughly `104.28 kB` in production builds after lazy-loading follow-through.
- Windows low-memory mode now skips terminal prewarm and shortens the default Ollama keep-alive.
- The launcher now requests a lower WebView2 memory target when hidden or inactive, and returns to normal when shown/focused.
- Measured Windows debug app-only memory after the native pass:
  - hidden steady state: about `77.7 MB` working set / `126.7 MB` private memory
  - after re-activation: about `148.2 MB` working set / `125.7 MB` private memory

## Validation

- `npm run verify`
- `npm run tauri dev`
- `cargo run --manifest-path src-tauri/Cargo.toml --bin keynova -- start|status|down`
