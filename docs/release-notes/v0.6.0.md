# Keynova v0.6.0

## Highlights

- Keynova's core workflow is now more useful as a keyboard-first local dispatcher
  for technical work.
- Search ranking is more transparent and more practical for daily project use:
  current-workspace/config matches get a visible boost, apps/folders are less
  buried, and generated/dependency paths are demoted instead of hidden.
- Project commands from common manifests are discoverable from search and remain
  copy-only, keeping command execution in the user's terminal.
- Developer utilities are easier to reach: slashless queries such as `json ...`,
  `jwt ...`, `hash ...`, `regex ...`, `color ...`, and `cron ...` produce inline
  results that can be copied directly.
- File previews are more useful, with bounded text/docx preview copy support and
  existing confirmation gates preserved for risky file actions.

## What Changed

- Added workspace/config/kind/noise score components and surfaced rank reasons in
  the UI.
- Kept search global while ranking active-workspace results higher, avoiding the
  earlier app/out-of-repo hiding problem.
- Added project-command discovery for `package.json`, `Cargo.toml`, `Makefile`,
  and `justfile` with copy-only primary actions.
- Added startup project-root detection using VCS roots first, so `tauri dev`
  launched from `src-tauri/` still resolves the repository root.
- Added slashless utility search rows and inline command-result rendering.
- Added copy buttons for text previews and inline command results; `Ctrl+C`
  copies the visible inline command result when no input text is selected.
- Updated generated-command and project-command wording to review/copy semantics,
  avoiding terminal-execution promises.
- Tightened `fix` capability output toward concise next-step guidance while
  keeping suggested commands user-run only.
- Prevented `next` suggestions from learning/suggesting their own `suggest_next`
  calls.
- Added CI-level keyboard regression coverage for zero-mouse search-result paths,
  capability Enter/IME behavior, and dispatcher mode boundaries.

## Safety Notes

- This release does not add project-command execution or terminal handoff.
  Discovered commands are copied to the clipboard for the user to review and run.
- `killport <port> kill` still does not terminate processes directly without a
  dedicated approval flow.
- Risky file actions continue to use preview/confirm behavior.
- The app remains unsigned.
