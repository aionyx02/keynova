# Keynova v0.7.0

The product is sharper: a sizeable cleanup removes dormant subsystems while the
search-first daily path gains useful inline AI, transparent ranking, project
profiles, and trusted-release groundwork.

## Highlights

- **Useful inline AI (copy-only).** `explain`, `summarize`, `fix`, `cmd`, and
  `next` produce stable, source-attributed output from the search box — no chat
  window. Generated commands stay copy-only; nothing runs on your behalf.
- **Transparent, practical ranking.** `suggest_next` now blends frequency,
  workspace affinity, and success rate, so your reliable commands surface first.
- **Workspace command profiles.** The `profile` prefix shows a project's
  signature commands, reliability-weighted, replayable from the keyboard.
- **Proactive next step + stability.** An idle `next` surface offers your likely
  next action; a backend crash-log panic hook feeds the `/diag` report.
- **Trusted-release groundwork.** `/diag` exports a redacted diagnostics bundle;
  a dormant GitHub-Releases updater and a secret-gated signing pipeline are
  scaffolded; corrupt `config.toml` is quarantined instead of silently lost.
- **Secrets in the OS keychain.** API keys move out of plaintext `config.toml`
  into the OS credential store (Windows Credential Manager / macOS Keychain /
  Linux secret-service), with a one-time migration on first run.
- **Supply-chain CI.** Dependabot + CodeQL scanning across npm, Cargo, and GitHub
  Actions.

## What Changed

- Hardened all five inline capabilities with source-display contracts and
  risk-tagged, copy-only command handling.
- Added project-scoped command profiles (`profile` prefix) and per-project
  workflow ranking signals (frequency × workspace × success rate).
- Added the idle proactive `next` surface and a process-level crash-log hook
  surfaced through `/diag`.
- Added the redacted `/diag` diagnostics bundle, a dormant in-app updater, the
  secret-gated code-signing pipeline scaffold, and corrupt-config quarantine.
- Moved at-rest secrets to the OS keychain (`keyring`); `config.toml` keeps only
  a reference.
- Added Dependabot + CodeQL workflows; reconciled `docs/security.md` with current
  reality (keychain, tightened CSP).

## Removed

- **Legacy ReAct agent runtime, Neovim/LazyVim integration, and mouse-control
  mode** — dormant subsystems cut to focus on the search-first core.
- **Per-workspace pinned commands** — surfaced only behind the `profile` prefix
  and overlapped the automatic ranker; removed before it ever shipped.

## Fixes

- **Ctrl+K no longer reopens after closing.** An explicit hide now cancels the
  focus-guard that keeps the launcher open while typing, closing a timing race
  where closing right after a keystroke could re-show the window.
- Restored full-width row layout in the `next` / `profile` result lists.

## Safety Notes

- The app remains **unsigned**; the signing pipeline is scaffolded but certs are
  not yet configured (SmartScreen / Gatekeeper will still warn).
- AI-generated commands are **copy-only**; there is no generic shell execution.
- At-rest secrets live in the OS keychain; risky file actions keep their
  preview/confirm gates.
